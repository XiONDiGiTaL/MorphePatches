01 / The collection

Four patches, one app

Tandem: Language exchange, net.tandem 6.38.0. Fifteen method anchors across classes.dex, classes2.dex and classes4.dex.

01 Required

Bypass PairIP checks

Skips PairIP's APK signature and Play licence checks, which otherwise stop a re-signed build from starting. Any patched Tandem build needs this one.

integrity Experimental
02 Default on

Force dark mode

Turns on Tandem's own dark theme, regardless of the system dark-mode setting. Uses the app's existing theme switch rather than recolouring anything by hand.

interface Experimental
03 Default on

Remove ads

Removes Tandem's community ad slot and stops the bundled AppLovin MAX and Meta Audience Network SDKs from requesting ads.

ads Experimental
04 Default on

Disable Adjust tracking

Stops the bundled Adjust attribution SDK from initialising, so no install, session or event attribution gets sent.

tracking Experimental

02 / Install

Three steps, no build

You need Morphe Manager and a stock Tandem 6.38.0 APK or APKM. That's it.

STEP 01

Add the source

Open the add-source link and confirm it in Morphe, or add XiONDiGiTaL/MorphePatches by hand. The four patches then appear inside Morphe.

STEP 02

Select your Tandem file

Pick a stock 6.38.0 (versionCode 11568) APK or APKM. Any other version is refused instead of being patched blindly.

STEP 03

Keep PairIP bypass enabled

Patch, then install the re-signed build. Leave Bypass PairIP checks on — without it the patched app won't start.

Prefer a file?

Import patches.mpp straight into Morphe Manager — from the v1.0.0 release or from the repository. Same four patches, no source needed.

Where this stands

The patches build, load and apply to the real 6.38.0 dex files, and every fingerprint anchor was verified against that APK. None of it has been run on a device yet, which is why every patch is listed as Experimental. When a patch has been confirmed on hardware, that status changes — not before.
